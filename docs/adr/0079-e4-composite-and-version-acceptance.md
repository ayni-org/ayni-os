# ADR-0079：完整 E4 组合、订阅依赖与版本拒绝

- **状态**：已接受；交付结果见本阶段 PR
- **日期**：2026-10-28
- **关联**：MA-033、计划 §10.5；ADR-0038、0054、0063、0075～0078

## 背景

正常 E4 只验证无中断的采样/分析/通知，不能证明各提交边界、父组合停止、旧语义查询和不支持格式的数据保留。用户授权按完整 E2→E1→E3→E4 推进，并要求各阶段提交后独立审查、修复及最终 CI 通过后合并。

## 决策

1. **职责与组合。** 应用注册 `composite.parent` 的权限上限和 `composite_workflow`，由 Core 保存父子关系、步骤、来源和调用。工作流依次完成可计数动作、Task 订阅采样、历史分析、原子派生记忆、确认采样停止和通知。runtime 只选择现有 ActionService、双用途 Mock 模型、SubscriptionProvider 与独立执行端，不在 Core 添加业务分支。
2. **切断。** 对动作回执、采样 PREPARED/派发、分析 PREPARED/派发/回执、派生记忆、采样停止、通知 PREPARED/回执及 Task 完成，共 11 个实际 append 边界，分别切为丢失或完整持久；另验派生记忆批次撕裂。测试专属探针按原 Call/Batch/Record codec 找到目标步骤，不复制布局。未持久的策略决定可重新规划；已持久调用保留 logical_call/operation，已完成副作用不重做。
3. **未知与停止。** 突然丢失的采样若无停止/查询证明，保留 UNKNOWN，不能冒充正常关闭后自动开新代。相应恢复路径验证依赖阻断；确认停止及结果已持久的路径验证接续完成。已接受的历史分析可以完成，但采样停止未确认时不产生新候选或通知；不把历史分析用于运动准入。父取消分别记录取消请求、未归还采样借用、独立执行端停止和资源归还。
4. **来源与通知。** 删除或撤销共享先于旧分析回执时，旧结果不能派生记忆或通知；重启仍保留失效。采样旧尾部通过当前仍有效的 sink 投递并明确拒绝，不访问旧 arena。通知入列与呈现分开：入列重启后可能 UNKNOWN，不能自动重放；成功回执先持久再完成 Task，失败/未知保留待处理，重复回执不重复完成。
5. **三类版本。** 兼容策略 reader 保留完整检查点；缺失旧能力/Binding、GoalType 或 Scene 时保留旧语义并阻断。旧查询 resolver 只有读原 operation 的能力，没有旧 Binding 或执行入口。`e4-compatibility.json` 声明的 reader/writer 行由实际 CLI 轨迹逐项核对；不把模拟 reader 当旧固件二进制。
6. **开发期存储边界（产品语义，用户 2026-10-28 已确认）。** 不制作迁移器或旧格式兼容 reader；原 `migration_interrupted` 不适用。以真实已包含动作、模型计数和删除的镜像，改写为 CRC 正确的不支持 schema 0/1/3 或必需记录版本；当前 reader 须受限、不安装 writer、不输出并原样保留。再次重启仍拒绝，不能回旧快照执行。真实 OTA 与迁移仍属 M4。
7. **typed 验收边界（产品语义，用户 2026-10-28 选择推荐项）。** M1 公开注册接口接受 typed 描述，没有 JSON Schema 注册入口。原关键字用例留到 MA-007 管理协议；本阶段验证非法类型/格式、缺少时限和越界文本上限明确拒绝。typed 的零字节上限明确表示只允许空文本，不当作缺失上限。C-JSON-012 的关键字解析继续未验证。
8. **整轮工具限额。** 九项提议不能退化为前八项加正文。E4 暴露 Mock 的该问题，解析器现在整轮报告 MODEL_OUTPUT / CAPACITY_EXCEEDED；通过真实授权工具视图核对没有已公开的八项前缀或通知副作用。

## 后果

Core、公共 ABI 0.45、schema 2 及默认生产配置均不变。新增有限夹具容量只影响本阶段 Native profile。完整 E4 按本次用户决定验收 typed 与不支持版本拒绝；JSON Schema 关键字、迁移、旧固件二进制、硬件停止和媒体/耐久各自保持未验证。

## 备选方案

不使用普通关闭替代断电，不将所有恢复路径都要求自动完成，不新增通用工作流 DSL、迁移器、生产协议或第二套持久重试。按完整阶段一个 PR 交付，按应用语义、端口/生命周期、切断与版本证据、数据/校验分域审查；约 1,700 行实现服务于一个可独立验收的阶段，不拆散其证据链。

## 验证

Native/Sim 的 46 项 E4 用例、11 项提交边界的丢失/完整持久及额外撕裂、兼容矩阵和 CLI 两轮重放已通过。相关回归、独立审查与最终 CI 的执行结论集中本阶段 PR。E4 后停止本轮实施；安全分支覆盖专项、Core Alpha 报告、完整 MA-038、M2 与硬件仍另行安排。
