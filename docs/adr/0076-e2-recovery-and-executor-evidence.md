# ADR-0076：E2 精确提交切断与独立执行端证据

- **状态**：已接受；已实施，交付检查见 #98
- **日期**：2026-10-28
- **关联**：MA-022、计划 §10.3；ADR-0026/0027、0045、0049～0052、0075；E2 F0～F14

## 背景

运行器已有故障生命周期，但仅按 step 切断不能证明切在 Task、授权或结果应用批次内部。计数动作也不能证明许可未签发、迟到续租不延长截止、Kernel 停止时执行端独立收敛。这些证据须来自真实异步存储、Core 签发路径及同一个独立许可门。

## 决策

1. **测试专属精确探针。** `tests/experiments/record_cut.cpp` 仅在 `AYNI_BUILD_TESTS=ON` 编译，并仅在该目标增加 Core 私有 include。探针用现有 Batch/Record/Call codec 查找实际待决 append 中的记录边界；不复制布局、偏移、校验或恢复规则。runtime 只接收闭集边界名，未开放 Core 内部状态或持久格式 API。关闭测试时相同动作明确返回 `UNSUPPORTED`。
2. **镜像归 Host。** Sim Host 复制待决 append 后保留实际前缀再断电；非法长度、已持久重试的截断均拒绝，失败保留 arena 与借用。区分未封口 torn tail 与已封口损坏批次，后者必须只读受限。此证据是 Sim Host framing，不替代 Native 文件外层 CRC、硬件 Flash 或耐久试验。
3. **独立物理模拟。** 组合根另装配现有 Mock executor、公开 Scene/Observation、资源和物理 Binding，Core 仍是唯一许可签发者。执行器模拟丢包、只延迟续租、可信本地代际/联锁变化及断电；旧 Kernel 丢弃前同步结束所有 completion 借用，但原物理许可仍按本地时钟到期。执行器自身重启返回未知、默认失能、增加执行代际，回调上下文保持稳定。
4. **实际许可与时间。** 延迟、重放使用实际收到的 Core 许可/续租。逐本地周期记录输出与停止测量，不以 Core 状态替代。91 ms 签 nonce、92 ms 撤销、95 ms 收包的场景断言截止 191 ms，而非 195 ms；续租到达旧截止之后不得恢复。停止测量采用 Mock 的自动确认、零物理停止延时；真实设备停止上限仍未验证。
5. **完整 E2 闭环。** 原清单全部变体进入编译脚本，并由测试核对原 ID 防止漏项。结果应用同时提交派生摘要、步骤与私有检查点；撕裂回滚后重评、已提交重启及重复回执均断言一份摘要、一个版本、同一调用和一次副作用。命令保留窗口通过实际填满命令表后验证，不以 ID 跳号代替驱逐。

6. **满盘下的关闭。** 实验暴露 Core 在 DRAINING 不刷新 StorageBudget，满盘缓存会令已准备但未派发的调用永久卡住。关闭期间继续从非阻塞 Host 端口刷新容量，但不启动新 compaction，也不清除既有逻辑日志上限；无空间或需要 compaction 时复用既有 closing 路径，仅归还易失借用，不伪造持久取消。有空间恢复则正常持久排空。Core 未新增字段，ABI/存储布局不变。

## 后果

新增构建依赖只服务测试探针；Mock 的链接显式声明其使用的 Core C ABI，源码依赖仍仅为公开头。Host、Provider 和组合根分别拥有镜像、独立输出及实验脚本，Core 仅修复上述关闭缺陷；公共 C ABI/schema 2 未改。后续 E1/E3/E4 复用这些有界控制，不引入另一套恢复或授权机制。

## 备选方案

- 猜测第 N 次 step 的内部记录位置：不能证明真实切断点，拒绝。
- runtime 直接解析持久字节：会形成第二套 codec，拒绝；现有属主 codec 只在 tests 中使用。
- 构造新许可或读取已释放 mailbox 模拟旧包：不能证明实际签发链，且生命周期不成立，拒绝。
- 用计数动作替代物理矩阵：无法证明独立停止和 nonce 时序，拒绝。

## 验证

E2 原清单与附加闭环场景、本地相关正常及原受管理执行回归通过；逐用例脚本和共用执行器可从仓库重放。具体命令、独立审查、最终 CI、限制与产物验证集中在 [#98](https://github.com/RobotSe7en/ayni/pull/98)。合并后本部分统一测量的 Core 行覆盖达标，沿用范围的安全分支覆盖仍未达标，结果在 #98，不以本实验替代独立覆盖收尾。E1/E3/E4、硬件、独立安全覆盖与 Core Alpha 仍未验收。
