# ADR-0049：独立执行端许可门

- **状态**：已接受；完整有界包络由用户 2026-10-25 确认
- **日期**：2026-10-25
- **关联**：MA-018B；ADR-0001、0005、0009、0045；C-PERMIT-003、004、006～008、010、012；C-STOP-006

## 背景

#67 已交付可复用异步 Mock，Core 仍拒绝物理调用。执行许可同时涉及本地执行、Core 持久签发、Scene 与停止账本；先交付可独立运行和验证的本地许可门，再在同一调用主干接入签发与停止确认。该拆分有独立 C ABI、内存及依赖验证边界，不为当前 Core 增加临时执行入口，也不把本地校验等同于完整 MA-018B。

## 决策

1. `control/permit_gate` 拥有一个执行域/控制模式的完整本地校验状态。仅依赖正式 C 类型，不链接 Core；调用方提供固定大小、对齐的内存。创建时复制可信设备限值、代际与租期上限，默认无许可、无输出。配置不提供“万能”硬件默认限值。
2. **包络表示（架构选项，用户 2026-10-25 选定推荐项）：** 许可携带最多 8 个数值字段的完整闭区间、字段名与显式单位，首版不使用草案中的摘要引用。字段顺序无意义，重复、缺失、额外字段和单位变化均拒绝；规范化的请求包络须逐项包含于设备限值。此处不决定设备间消息格式，不承诺字符串/媒体是执行器控制量；Core 的通用能力参数另有契约。
3. 非零 `permit_id` 在同一配置 Kernel boot 内严格递增；保留最后终态身份，拒绝重复或更旧许可。每次创建新的 gate 必须使用新的 `executor_boot_epoch`，即使硬件未重启，避免 nonce 和 permit 高水位重置后复用旧授权。该代际由可信组合根持有，库不建立全局注册表或伪造持久性。
4. 执行端保存最近 8 个 nonce 及其本地签发时刻。许可截止为 `t_N + L`；会话续租仅取与现有截止的最大值，不改变模式、包络、operation 或代际。过程不续租。到达截止即进入停止阶段，迟到续租不能复活；未知、淘汰、已过期 nonce 和时间溢出明确拒绝。
5. 只有接受第一条合规样本后控制周期检查才能返回 OK。每条样本绑定 permit、递增 sequence、执行端本地采集时刻及完整字段值。每周期检查全部代际、持续联锁、租期和最后样本年龄；越界不截断照做。样本过旧也停止，即使许可租期未到。远端首次到达时刻不能冒充采集时刻；跨设备采样新鲜度协议未实现。
6. 无许可、活动、待停止确认、已确认停止由单一执行事实及可选样本/停止事实派生；没有分散的启用布尔组合。停止请求或到期立即禁止样本，仍须可信本地测量调用确认。确认只证明本地停止事实，不证明目标达成、日志持久或 Core 资源已释放；重复确认保留原测量时刻。存在活动/未确认执行时销毁返回 BUSY。
7. 时钟倒退禁止输出与后续许可，须停止后用新代际重建；可信的新停止测量仍可用于释放本地对象，不清除该时钟故障。所有端口同一执行端线程、不可 ISR 并发调用；真实本地急停、硬件监督和驱动关闭由执行适配器及独立停止链承担，库不声称能在调用线程失效后关断硬件。
8. ABI 升至 0.34；公共共享类型及 gate 函数在 `include/ayni/control.h`，实现库单独链接，gate 创建配置也检查 exact ABI major/minor，独立部署不能绕过版本匹配。草案头转用正式许可类型，未实现的目标验证/停止账本类型仍保持草案。C99 布局、独立链接与无堆符号检查覆盖此边界；Core 容量与 storage schema 2 不变。

## 后果

更换执行器时，适配器提供实测限值、代际和持续联锁，并将非 OK 结果落实为输出禁用；许可门无需 Core 私有头或硬件 SDK。后续 Core `resources/permit` 只负责授权准入、持久屏障后的签发/续租和隔离；`work` 持有控制会话及动作/停止事实。Scene、Observation 和可信 owner 管理仍由其属主模块完成。

完整包络比摘要大，原型每条许可 808 B；M1 用固定内存和显式容量承担此成本，不据 Native 大小宣称 ESP32 可用。执行端重新创建必须更换代际、可信发送路径必须认证 owner，均是实际适配器契约，不能由纯数值匹配替代。

## 备选方案

- gate 包含 Core 的 Scope 或资源表：会倒置依赖方向，无法独立部署，故不采用。控制边界本地校验有界字段标识；不引入 Core 链接来复用很小的字符判定。
- 仅传摘要并另建参数缓存：减少消息体，但增加缓存身份、失效和摘要冲突约束；首版采用用户确认的完整包络。
- 取消受理直接标记停止：没有本地测量依据，不能据此释放执行器，故不采用。
- 把租期作为唯一样本期限：会在连续控制输入停止后继续使用旧控制值，故独立校验样本年龄。

## 验证

正常 C ABI 场景覆盖初始禁用、文本标识/数值包络、nonce 锚定、会话续租、过程到期、样本年龄及递增序号、停止与确认分离、旧许可拒绝和显式容量/布局边界。新增故障、传播竞态、重启/恢复专项仍暂停；Core 签发、Scene、资源隔离闭环和真实执行器未在本部分验收。本地正常验证、独立审查及完整现有 CI 通过，已合并；命令、结果及 CI 集中记录在 [PR #68](https://github.com/RobotSe7en/ayni/pull/68)。
