# ADR-0042：运行限制、直连模型及 M1 剩余交付边界

- **状态**：已接受（用户 2026-10-25 批准实施计划；实现状态另见进度页）
- **日期**：2026-10-25
- **关联**：计划 §2.3、§5.1、§9.1、§14.1；MA-018、MA-008；[实施顺序](../../reports/core/m1-remaining-implementation.md)

## 背景

用户使用外部模型 API，不提供模型计费服务。原计划的分层额度、预留结算与自建认证网关不再是产品需求。资源占用、调用失控和未知副作用仍需由本机机制约束。执行许可依赖 MA-008 的动作账本与持久派发屏障，因此不能简单做完全部 MA-018 后才开始 MA-008。

## 决策

1. **产品语义，用户选定**：仅保留并发、单次超时、每 Task 模型调用次数、输入/输出字节与后台频率限制；取消设备/Agent/Goal/Task 累计钱包、金额、充值、费用预留及结算。旧 `C-BUDGET-*` 编号保留并废止，新增 `C-RUN-*` 条款。存储 `StorageBudget` 与 step 工作项/时间预算不受影响。
2. **产品语义，用户选定**：同优先级按 Agent 实例轮转，同实例 FIFO。一次资源组全有或全无；一个实例的队首等待不阻塞其他实例可用的资源；优先级不抢占正在执行的工作。停止链不排队。
3. **产品语义，用户选定**：Task 达运行上限时暂停并保留进度、计数。只有所有者认证管理命令可提高上限并解除该项暂停；普通恢复不清零，模型不能提高，启动时的硬容量不可越过。
4. **产品语义，用户选定**：直连外部 OpenAI-compatible Chat Completions；先做非流式文本及函数工具调用。base URL、model、密钥引用在运行时配置，密钥不进入 Core、日志或提交；无自动换服务/换参数重试。
5. **产品语义，用户选定**：暂停助理是持久控制组，包含暂停期间新建的自主工作；提醒和显式用户工作不在该组。Core 只管理通用组，可信应用决定归属。记忆表满拒绝新写入并保留已有数据。
6. **接口与架构**：Core 使用有界 typed 结构；JSON、HTTP、厂商 SDK 在 Provider 边界。静态资源描述归 `catalog/resource`，占用、排队与隔离归 `resources/admission`；Task 运行计数归 `work/task`；调用与动作账本归 `work/call` / `work/action`。Kernel 编排同批提交，不复制各属主的状态。
7. **交付依赖**：018A 资源/运行限制 → 008A 调用/账本/完成槽 → 018B 许可/最小 Scene/停止 → 008B 订阅/观察 → 008C 真实文本 Provider → 双策略、记忆/日历、助理、SDK/CLI。不开临时派发入口绕过屏障。
8. **兼容**：优先兼容扩展；确需破坏存储时显式拒绝并保留原状态目录，以新目录运行，本轮不制作迁移工具。ABI、存储与线协议各自版本化，不复用草案中已冲突的意图编号。
9. **验证，用户选定**：相关正常测试继续；新故障/恢复专项及变异活动保持暂停，不在包末自动补做。原有测试保留。实现及普通集成完成不能写成完整 E1–E4、Core Alpha 或实机验收通过。

## 2026-10-25 补充决定

10. **产品语义，用户选定推荐项**：普通对话保存当前 Task 所需的有界输入与回答正文，支持重启后继续；删除接入记忆与隐私机制，不保存密钥或原始媒体。正文属于受权限与删除约束的业务持久数据，不进入错误详情、诊断日志或通用遥测；不扩展为无限对话归档。具体字节限额随调用 Schema 配置，有界容量不足明确拒绝。实现归 MA-008 / MA-011，当前完成槽不代表已持久保存正文。

## 后果

不创建空的 `budget/` 实现。B2/B4 的业务原子性、对外副作用身份与持久屏障继续成立，但不包含已取消的费用账本。一个 Task 达上限不阻止其他工作，未知结果仍不得盲目重试。软件取消 HTTP 不代表远端未执行。

M1 提供 Native CLI、双 Agent、可替换 Mock/文本 Provider 和模拟执行端。ESP-IDF 存储、Web、音频、屏幕及真实执行器均须其所属阶段的独立实现与证据。MA-038 可先验证 typed FakeTransport；IDL/线格式仍在 ESP32 量测后、解码器实现前决定。

## 备选方案

保留钱包和网关会增加不需要的服务运维与计费状态；用单一 FIFO 会让高频实例压住其他实例；先做许可再建立账本会产生两套派发状态。这三项均不采用。

## 验证

[PR #60](https://github.com/RobotSe7en/ayni/pull/60) 实现资源目录、健康查询和有界全组准入机制；相关 Native 正常场景、C99 ABI、无堆及依赖检查通过，独立审查发现的旧停止确认问题已用占用代际修复并复核。ABI 0.29 不改变存储 schema 2。资源机制作为可独立验证的前置能力交付；Task 运行限制与调用账本/消费链仍待后续实现，其余本 ADR 所列能力仍是计划。故障、恢复和硬件证据仍单独列明。
