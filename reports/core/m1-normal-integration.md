## 交付范围

Native 已有两个 Agent 的文本/工具回合、私有记忆与共享/撤销、可信日历提醒、Mock 设备检查/持续观察、统一助理暂停、通知与安静时段，以及公开 C++ SDK 和四个接入示例。P6 为这些能力补充可重放的正常组合证据。真实模型短文本/工具验证沿用 #75；本轮没有付费请求，用户本机的真实模型多轮试用仍待完成。

| 用例 | 实际观察到的正常行为 | 边界 |
| --- | --- | --- |

## 多节点正常子集

MA038-N1 使用两个独立 Kernel、时钟和存储，实际验证只推进 A 不改变 B 的时钟/持久前缀。两个正常远程操作分别经过源端目的地 Scope 和接收端本机 Grant；源 Task 的 ID/owner 保持，接收端以固定服务实例创建独立 Task。两端本地输入先于远端效果完成；执行中/完成查询及第二次调用的在途正常关闭都有实际产物。

节点限定身份允许数值碰撞，不能把两端相同数值的 instance/Task ID 当成同一对象。typed 通道由组合根预配置，服务 Task 选择仍为“按推荐项实现，改选再改”（ADR-0070），没有记作用户已确认。RAM 映射、预配置 peer 和查询汇总不等同于持久协议去重、生产认证、NOT_ACCEPTED 墓碑或分区/恢复保证。

F18 使用最大配置，公开 API 实际填满 Goal、Task、Grant 和 Memory，Task 步骤/检查点及 Goal/Memory 正文字节也取对应上限。Call=0，未填满的目录、资源占用和来源依赖明确保留。模拟 Host 的逻辑存储额度为 1 GiB，以覆盖保守快照预留，不预分配同等 RAM。

GCC Release 无 sanitizer 的观测：单条记忆编码最大约 0.212 ms，批量停止实例编码最大约 1.277 ms；单次满表本地事件的八个工作 step 最大约 0.212 ms。填充/排空与静止 step 分开统计，编码包含 finish，管理提交另计。样本数、p99、精确值和编码/快照/缓冲界限在 #91；一次最大值不是 WCET，未约定的 Native 硬预算不据此宣告通过或失败。保留当前扫描，优化依具体预算与 M2 数据再决定（ADR-0069）。

## 覆盖率与差距

在冻结源码 `d98149165fe9bbdc194545d0f1ab2bdc34d75a82` 上完成一次新的 GCC 13.3 Debug、atomic coverage、无 sanitizer 的完整测试与模拟器测量。之后的收集器修复仅加强输入完整性守卫；复核同一原始 JSON，聚合数值不变，没有重跑全套追数。

- Core 行覆盖 **92.14%**，达到 75% 目标；所有 Core `.cpp` 和既有安全范围 C/C++ 实现均有数据，零执行分支仍在分母。
- 沿用 P4 保守范围的安全相关分支覆盖 **75.36%**，**未达到 90% 目标**。范围为全部 `core/`、`control/permit_gate/`、`providers/mock/`、`providers/mock_execution/` 及其 TU 中的头文件，不缩范围或去掉防御/恢复分支。
- 44 个无 gcov 条目的 Core 头已逐项检查：43 个为声明/数据/常量头，一个是 `record_types.h` 的编译期 `all_distinct()` / `static_assert`。未发现可单列的未实例化运行时函数体；默认初始化和编译期求值不据此宣称运行时覆盖。

当前测试全集未执行足够的分支组合；本轮没有把未覆盖分支统称为不可达，也没有因为指标差距恢复暂停的专项。90% 目标和完整安全/Alpha 验收继续开放（ADR-0071）。精确分子/分母、范围、命令和验证在 #93；原始 gcov/JSON 保存在本机构建目录，未上传为仓库/CI 附件，统计工具与复现方法已入库。
