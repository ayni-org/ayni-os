# M1 剩余能力实施顺序

依据用户 2026-10-25 批准的计划与 [ADR-0042](../../docs/adr/0042-runtime-limits-and-direct-model-access.md)。当前交接入口仍为 [m1-progress.md](m1-progress.md)。每行是可审查的完整能力，前置清理/编码/API/测试用独立提交组织；不因正常测试通过宣称专项验收完成。

| 顺序 | 能力 | 实施及验收边界 | 状态 |
|---|---|---|---|
| 0 | 产品约束 | 废止费用额度，记录直连 API、公平性、持久暂停、满表拒绝及测试边界 | 已记录 ADR-0042，待合并 |
| 1 | MA-018A | 可信静态资源目录；运行健康/占用/隔离；全有或全无；Agent 轮转、实例 FIFO；等待原因/期限；Task 持久调用次数与所有者提高上限 | 资源机制已实现，运行限制/调用消费仍待实现 |
| 2 | MA-008A | 统一调用与稳定步骤身份，Binding 校验，ActionRecord、PREPARED/DISPATCHING 持久屏障，最终复核；进度/取消/终态可靠完成槽；B4 原子应用；Mock A/B；排空关闭 | 未开始 |
| 3 | MA-018B | 过程与控制会话、nonce 锚定续租、到期不可恢复、即时授权门控、最小 Scene；停止确认前隔离；独立模拟执行端/停止链 | 未开始 |
| 4 | MA-008B | 订阅 open/renew/close、代际/序号/gap、TTL/质量、媒体引用；新代际与依赖复核；可靠控制回执 | 未开始 |
| 5 | MA-008C | libcurl multi 工作线程、yyjson 有界解析；运行时 endpoint/model/secret；非流式文本与工具调用；本地协议夹具；实 API 单独验证 | 未开始 |
| 6 | MA-009 | 规则和 ToolLoop 两策略；单轮最多 8 调用、首版顺序；命名版本步骤；未知阻止后续；检查点明确兼容；补偿新调用新授权 | 未开始 |
| 7 | MA-011A | 私有命名空间与所有者公共档案；来源/版本/确认状态；有限检索与上下文；tombstone 立即拒绝传递派生依赖、有界擦除；满表拒绝 | 未开始 |

| 9 | MA-019 | 文本回合与提醒/设备检查/记忆整理/场景观察；通用持久暂停组、可信应用归类、新工作同样受限；通知成功呈现才完成、安静时段 | 未开始 |
| 10 | MA-020 | C++17 包装、显式排空/关闭、Native 管理 CLI；四个接入/组合示例只用公开 API；runtime 装配；双 Agent 演示 | 未开始 |
| 11 | E1–E4 正常子场景 | 可复现 JSON 夹具/轨迹；公平/私有/限制、正常屏障、策略/Provider 切换与组合；独立子用例 ID，不冒充原完整实验 | 未开始 |
| 12 | MA-038 正常子集 | 多独立 Kernel/时钟/存储、typed FakeTransport、固定 owner 的正常远程调用及查询；IDL/解码器和故障矩阵另候条件 | 未开始 |

实现通则：复用现有授权目录、命令幂等、提交协调和记录 codec；不从模型接受驱动/资源锁或任意端点。Provider 线程只向预留槽投递，不能直接改 Core。可靠完成记录遇存储背压保留，不被 progress 覆盖。Task 普通恢复不重置调用计数；提高软限额不超过启动硬容量。默认模型槽 1、Task 模型调用 8、请求超时 30 秒；前台等待超限暂停、提醒可明确无界等待、后台跳过有计数；低容量配置可禁用尚不使用的表。

完成定义：每项有契约、实现、正常测试、作者设计自查和适用独立审查；本地按相关行为选择检查，CI 运行既有 ASan/UBSan 全套。ABI/容量变化量 arena，硬件数字另测。完整 E1–E4、Core Alpha、故障恢复、ESP32 烧录、Web/语音/屏幕均不能由本表的普通集成替代。
